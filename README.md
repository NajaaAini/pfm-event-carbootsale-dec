# pfm-event-carbootsale-dec
Aplikasi web interaktif untuk pengurusan acara Car Boot Sale Penang Ferry Museum. Menyediakan fungsi semakan status kelayakan vendor masa nyata berasaskan Google Sheets, paparan maklumat acara, countdown rasmi, harga sewa tapak, serta pautan pendaftaran dan sokongan khidmat pelanggan.
